# SnapTranslate

[中文](./README.md)

A lightweight browser translation extension.

## Features

- **Selection Translation** — Translate selected text instantly
- **Input Translation** — Translate text in input fields
- **Page Translation** — Full page translation with site-specific rules
- **Multiple Engines** — Google Translate and Bing Translate
- **Auto-Translate Blacklist** — Per-site control over auto-translation
- **Multi-language** — English / Chinese / Japanese / Korean

## Installation

### Load Unpacked (Development)

1. Clone: `git clone https://github.com/mitcehub/SnapTranslate.git`
2. Install: `cd SnapTranslate && npm install`
3. Build: `npm run build`
4. Open Chrome → `chrome://extensions`
5. Enable "Developer mode"
6. Click "Load unpacked" → select the `Translate` directory

### Install from Release

1. Download the latest `.zip` from [Releases](https://github.com/mitcehub/SnapTranslate/releases)
2. Extract to a local directory
3. Chrome → `chrome://extensions` → Developer mode → Load unpacked → Select the extracted directory
